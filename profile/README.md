# STRILK Labs

Application security, DevSecOps and security research.

STRILK helps software teams assess, validate and remediate security risks. Strilk-Labs is where we publish our research tools and technical documentation.

## What we do

- **Application security:** code review, technical validation and actionable fixes.
- **DevSecOps:** review CI/CD pipelines, dependencies, secrets handling and software delivery controls.
- **Security assessments:** scoped, authorized testing with findings reviewed by a security professional.
- **Remediation:** connect each finding to a corrective change, regression tests and retest results.
- **Security research:** study Windows internals, memory safety, virtualization and binary analysis, and develop tools that support detection and remediation.

Our approach follows the same cycle as [strilk.com](https://strilk.com/): **scope → validate → fix → verify**.
